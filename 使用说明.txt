360 残留清理工具  使用说明
========================================

一、先做（只读，绝对安全）
----------------------------------------
双击  1-Check.bat
它会扫描并列出 360 的运行进程、服务、驱动文件、注册表、卸载项、安装目录、
计划任务、开机启动项、启动文件夹和桌面快捷方式、防火墙规则、右键菜单/浏览器插件、
Defender 与安全中心的残留设置。不会改动任何东西。
如果显示“未发现 360 残留”，就说明没装过，直接删掉这个文件夹即可。

二、确认有残留，再清理
----------------------------------------
1. 先断网（拔网线或关 Wi-Fi），防止 360 联网把自己装回来
2. 关掉 360 的自我保护：主界面右上角菜单 → 设置 → 找 自我保护 / 自保护
3. 双击  2-Clean.bat （也可右键 → 以管理员身份运行），会弹出 UAC 提示，点“是”
4. 脚本会先建系统还原点、备份注册表，再逐项删除
5. 最后要求输入 YES 才会真删，输入其它内容即取消
6. 完成后重启电脑，再跑一次 1-Check.bat 复查

注意：清理会先结束所有 360 进程，再删服务、驱动、计划任务、防火墙规则、右键菜单、
注册表、360 的下载目录和 360 浏览器数据（书签、密码等）。需要保留的请先自行备份。
按用户安装的程序（360AI办公/360文档卫士在 %APPDATA%\Reader、清理Pro 等）也会连同
其本地数据（历史记录、备份）一起删除；它们会以“Reader”“SysCleanPro”这类名字出现，
不带 360 字样，脚本靠程序签名识别。

三、驱动残留（FileAbap64.sys）必须进安全模式清理
----------------------------------------
绝大多数项目在正常模式就能删干净，只有 360 的过滤驱动 FileAbap64.sys 例外：
它开机就加载，运行中会把自己重新写回去，正常模式下删多少次、重启多少次都没用。
体检结果里有 FileAbap64.sys 或 FileAbap 服务时，按下面做：

1. 先把本工具整个文件夹复制到桌面（安全模式没有网络，拷不进去）
2. 设置 → 系统 → 恢复 → 高级启动 → 立即重启
   → 疑难解答 → 高级选项 → 启动设置 → 重启 → 按 4 或 F4（启用安全模式）
3. 登录后桌面四角会显示“安全模式”，双击 2-Clean.bat，照常输入 YES
4. 清理完成后重启回正常模式，再跑一次 1-Check.bat

注意：安全模式下“任务计划”服务不启动，脚本会提示“任务计划服务未运行”，这是正常的，
      计划任务会在第 4 步的复查里补清。
      安全模式下没有网络，如需重新拷贝本工具，请选“安全模式（带网络）”。

四、备份文件在哪
----------------------------------------
D:\360clean_backup（电脑没有 D 盘时是 C:\360clean_backup）
里面是清理前的注册表备份 .reg 文件，双击可还原。
确认电脑一切正常后可以删掉。

五、收尾检查
----------------------------------------
1. 重启电脑，再双击 1-Check.bat 复查一次。显示“未发现 360 残留”就说明彻底干净了。
   如果还列出 FileAbap64.sys 或 FileAbap 服务，说明必须按第三节进安全模式清理。
2. 安全中心里如果还显示“360安全卫士”，脚本会一并删除（实测清理后重启不再出现）。
   若复查时仍然出现，说明还有 360 进程在运行，先跑一次 2-Clean.bat 再重启。
3. 如果清理后 Windows Defender 仍是关闭状态，去 Windows 安全中心 → 病毒和威胁防护，手动打开“实时保护”。
4. 浏览器主页、默认程序检查一遍，360 常会改这两处。
